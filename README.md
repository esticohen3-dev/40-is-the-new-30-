# 40 לטלאור – דף ברכות

דף שבו חברים ומשפחה משאירים ברכה (טקסט, תמונה, או סרטון של עד 30 שניות). מ-5 בפברואר 2027 טלאור רואה את כל הברכות.

## הקבצים
| קובץ | מה זה |
|---|---|
| `index.html` | הדף הראשי: ספירה לאחור, טופס, ומיום ההולדת קיר הברכות |
| `admin.html` + `admin.js` | דף המנהל (גם `?admin` בכתובת מפנה אליו) |
| `app.js` | הלוגיקה של הדף הראשי, כולל בדיקת גודל ואורך של הקובץ |
| `api.js` | קריאות לשרת |
| `config.js` | **הקובץ היחיד שעורכים**: כתובת השרת ותאריך יום ההולדת |
| `styles.css` | עיצוב |
| `apps-script/Code.gs` | צד השרת. מדביקים אותו ב-Apps Script (באתר עצמו הוא לא משמש) |

## הפעלה, לפי הסדר
1. **שרת:** לפי ההוראות ב-[`apps-script/README.md`](apps-script/README.md). בסוף יש ביד כתובת שמסתיימת ב-`/exec`.
2. **הגדרת הכתובת:** פותחים את `config.js` ומדביקים את הכתובת במקום `PASTE_WEB_APP_URL_HERE`.
3. **GitHub Pages:**
   1. נרשמים ל-[github.com](https://github.com) (אם עוד אין חשבון).
   2. **+ → New repository**. שם תמים, למשל `party-page` (השם מופיע בכתובת, אז לא `talor40`). מסמנים **Public**. לוחצים **Create repository**.
   3. בעמוד שנפתח לוחצים **uploading an existing file**. גוררים את כל הקבצים. לוחצים **Commit changes**.
   4. **Settings → Pages**. תחת "Branch" בוחרים `main` ו-`/ (root)`. לוחצים **Save**.
   5. אחרי דקה-שתיים הדף זמין בכתובת `https://<שם-המשתמש>.github.io/party-page/`.
4. **מוזמנים:** ממלאים בגיליון, בלשונית `מוזמנים`, את העמודות `שם` ו-`טלפון`. הסטטוס מתעדכן לבד.
5. **בדיקה** (מהטלפון):
   - ברכת טקסט, תמונה, וסרטון קצר.
   - סרטון של יותר מ-30 שניות. צריך להיחסם.
   - סרטון של כ-25-30MB בחיבור סלולרי. לוודא שהוא עובר.
   - `?admin`: כניסה, הסתרה, מחיקה. לוודא שהסטטוס בלשונית `מוזמנים` התעדכן.
   - דף הברכות. ההוראות ב-`apps-script/README.md`, בסעיף "בדיקת דף הברכות".
   - בסוף, למחוק את ברכות הבדיקה מדף המנהל.
6. **שליחת הקישור** למוזמנים.
7. **ביום ההולדת:** להיכנס בבוקר, לוודא שהתמונות והסרטונים מוצגים, ורק אז לשלוח לטלאור את הקישור.

## שינויים בקבצים אחרי ההעלאה
ב-GitHub נכנסים לקובץ, לוחצים ✏️, עורכים, ואז **Commit changes**. האתר מתעדכן אחרי דקה בערך.

## חשוב לדעת
- **הגבלת שליחות:** אין הגבלה לפי IP, כי Apps Script לא מקבל את כתובת ה-IP. במקומה יש הגבלה כללית של 20 שליחות בדקה, שדה honeypot נגד בוטים, ותקרה של 200 ברכות.
- **אורך הסרטון** נבדק רק בדפדפן. השרת בודק רק גודל, וגם שהקובץ הוא באמת תמונה או סרטון.
- **תמונות מוקטנות** בדפדפן ל-2048 פיקסלים לפני השליחה, כדי שההעלאה תהיה מהירה.
- **תמונות וסרטונים מוצגים מ-Google Drive.** סרטון שהועלה זה עתה יכול להופיע כמה דקות כ"בעיבוד".
- **בדף המנהל** מוצגת תמונה ממוזערת. לחיצה עליה פותחת את הקובץ ב-Drive (צריך להיות מחובר לחשבון גוגל שלך).
- **כניסה סודית לדף המנהל:** 5 לחיצות ברצף על העיגול הצהוב עם ה-40 (תוך 3 שניות). גם `admin.html` או `?admin` בכתובת עובדים.
- **סיסמת המנהל** נשמרת רק ב-Script Properties. היא לא נמצאת בשום קובץ ב-GitHub.
