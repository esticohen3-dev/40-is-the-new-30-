# הגדרת השרת (Google Apps Script)

## הקמה ראשונה

1. **יוצרים גיליון:** נכנסים ל-[sheets.new](https://sheets.new) וקוראים לקובץ `פרויקט עבודה` (שם תמים, כדי לשמור על ההפתעה).
   את הלשוניות לא צריך ליצור, `setup` יוצרת אותן.
2. **פותחים את העורך:** בגיליון בוחרים **Extensions → Apps Script** (בעברית: **תוספים → Apps Script**).
3. **מדביקים את הקוד:** מוחקים את כל מה שכתוב בקובץ `Code.gs` בעורך, ומדביקים במקומו את כל התוכן של הקובץ `Code.gs` מהתיקייה הזו. לוחצים 💾 (שמירה).
4. **מגדירים סיסמה:** בסרגל הצד לוחצים ⚙️ **Project Settings**, גוללים ל-**Script Properties** ולוחצים **Add script property**:
   - Property: `ADMIN_PASSWORD`
   - Value: סיסמה חזקה לבחירתך
   ולוחצים **Save script properties**.
5. **מריצים את setup:** חוזרים לעורך (אייקון `< >`), בוחרים בתפריט שליד הכפתור **Run** את הפונקציה `setup`, ולוחצים **Run**.
   - גוגל תבקש אישור הרשאות: **Review permissions**, בוחרים את החשבון שלך.
   - אם מופיע "Google hasn't verified this app": לוחצים **Advanced**, ואז **Go to ... (unsafe)**, ואז **Allow**. זה תקין, כי זה הסקריפט שלך.
   - בסוף מופיעה למטה ההודעה "✔ ההקמה הושלמה", עם קישור לתיקייה שנוצרה ב-Drive.

   `setup` יוצרת את הלשוניות `ברכות` ו-`מוזמנים` עם הכותרות, את התיקייה `פרויקט עבודה` ב-Drive, וטריגר שיפתח את הקבצים בחצות של יום ההולדת.
6. **מפרסמים:** לוחצים **Deploy → New deployment**, ליד "Select type" לוחצים ⚙️ ובוחרים **Web app**:
   - **Execute as:** `Me`
   - **Who has access:** `Anyone`
   - לוחצים **Deploy** ומעתיקים את ה-**Web app URL** (מסתיימת ב-`/exec`).

## ⚠️ אחרי כל שינוי בקוד
הכתובת ממשיכה להריץ את הגרסה הקודמת עד שמעדכנים אותה:
**Deploy → Manage deployments → ✏️ (עריכה) → Version: New version → Deploy**.
הכתובת עצמה לא משתנה. לא ליצור "New deployment" שוב, כי זה יוצר כתובת חדשה.

## בדיקת דף הברכות לפני יום ההולדת
1. ב-Script Properties מוסיפים `BIRTHDAY_DATE` עם הערך `2026-01-01T00:00:00+02:00` (תאריך שכבר עבר).
2. ב-`config.js` באתר משנים זמנית את `BIRTHDAY_DATE` לאותו תאריך.
3. בודקים את דף הברכות.
4. **מחזירים:** מוחקים את `BIRTHDAY_DATE` מ-Script Properties ומחזירים את `config.js`.
   לא להריץ את `setup` בזמן שהתאריך המזויף מוגדר, כי זה מוחק את הטריגר.

## מה יש ב-Script Properties
| מפתח | מה זה |
|---|---|
| `ADMIN_PASSWORD` | סיסמת דף המנהל. חובה. |
| `FOLDER_ID` | התיקייה ב-Drive. `setup` ממלאת לבד. |
| `BIRTHDAY_DATE` | אופציונלי, רק לבדיקות. |
| `FILES_SHARED` | נכתב אוטומטית אחרי שהקבצים נפתחו. לא לגעת. |

## אם משהו לא עובד
- **"Exception: You do not have permission"**: צריך להריץ שוב את `setup` ולאשר הרשאות.
- **הדף כותב "אין חיבור לשרת"**: לבדוק שהכתובת ב-`config.js` מסתיימת ב-`/exec` ושב-"Who has access" מוגדר `Anyone`.
- **הקבצים לא נפתחו ביום ההולדת**: בעורך בוחרים את הפונקציה `openFiles` ולוחצים **Run**. (גם הצפייה הראשונה בברכות מנסה לפתוח אותם לבד.)
- **יומן שגיאות**: בעורך, בסרגל הצד, **Executions**.
